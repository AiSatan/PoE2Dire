## ใช้งานอย่างไร?

0. ติดตั้งสำหรับเบราว์เซอร์ของคุณ: [Chrome](https://chromewebstore.google.com/detail/paekoknkbpfidmpabiikofkemegpfgnh?utm_source=item-share-cb)/[Firefox](https://addons.mozilla.org/en-US/firefox/addon/poe2dire/)
1. เปิดหน้ารายละเอียดการอัปเดตหน้าใดก็ได้ในฟอรัม Path of Exile ([หน้านี้กำลังได้รับความนิยม](https://www.pathofexile.com/forum/view-thread/3932540))
2. คลิกไอคอน PoE2Dire ด้านบนเพื่อเปิดใช้งาน <img width="114" height="79" alt="image" src="https://github.com/user-attachments/assets/2b800f16-d7a4-4f35-b4cc-65940e61ee31" /> (ถ้าไม่เห็นไอคอน ต้องปักหมุดก่อน โดยคลิกที่ไอคอนรูปตัวต่อ ค้นหาแล้วคลิกจากตรงนั้น)
3. เสร็จเรียบร้อย
4. คลิกอีกครั้งเพื่อปิดการใช้งาน หรือจะรีโหลดหน้าเว็บก็ได้

ตัวอย่างวิดีโอ: [https://www.youtube.com/watch?v=ES66rQrVNQY](https://www.youtube.com/watch?v=ES66rQrVNQY)


## ความสามารถ

- เริ่มพิมพ์เพื่อเปิดการค้นหา แค่พิมพ์คำที่ต้องการ ไม่ต้องทำอะไรอย่างอื่น
- สารบัญแบบของเราเอง สวยและใช้ง่าย!
- คำอธิบายไอเทมและสกิลเมื่อชี้เมาส์ จำไม่ได้ว่าไอเทมยูนีคชิ้นนั้นทำอะไร? แค่ชี้เมาส์ก็ดูคำอธิบายจากวิกิได้เลย!
- คำอธิบายคำสำคัญเมื่อชี้เมาส์ เพิ่งเริ่มเล่นและมีเวลาเล่นแค่ 5000 ชั่วโมงเหรอ? ไม่ต้องกังวล ชี้เมาส์ไปที่คำที่ไม่รู้จักอย่าง "aggregated" แล้วดูคำอธิบายเต็ม ๆ ได้เลย! (อ้างอิงจากหน้าคำสำคัญของ poewiki จึงใช้ได้กับ PoE เท่านั้น ผู้เล่น PoE2 อย่าเพิ่งสับสนนะ)

## ตัวเลือกการติดตั้ง


> รบกวนช่วยรีวิวให้หน่อย จะได้มีคนเจอส่วนขยายนี้มากขึ้น!


### ติดตั้งบน Chrome

[Chrome WebStore](https://chromewebstore.google.com/detail/paekoknkbpfidmpabiikofkemegpfgnh?utm_source=item-share-cb)

### ติดตั้งบน Firefox (ใช้ได้กับ Firefox บนมือถือด้วย)

[หน้าส่วนเสริมของ Firefox](https://addons.mozilla.org/en-US/firefox/addon/poe2dire/)

### ติดตั้งเป็น userscript

> [!CAUTION]
> ส่วนนี้สำหรับผู้ที่รู้จัก userscript อยู่แล้ว

หวังว่าคุณคงรู้วิธีติดตั้งสคริปต์ลงใน "monkey" ของคุณอยู่แล้ว คุณสามารถดาวน์โหลด `PoE2Dire.user.js` ได้จากหน้า [GitHub Releases](https://github.com/aisatan/PoE2Dire/releases) นี่คือตัวอย่างวิดีโอสำหรับ ViolentMonkey: [https://www.youtube.com/watch?v=cgWVGSAxoEY](https://www.youtube.com/watch?v=cgWVGSAxoEY)

> มีข่าวลือว่า "คุณสามารถลิงก์ตรงไปยังไฟล์ .js ดิบได้จากหน้าติดตั้ง"

สรุปขั้นตอนคร่าว ๆ ดังนี้:

1. ดาวน์โหลดไฟล์ `PoE2Dire.user.js` จาก [GitHub Releases](https://github.com/aisatan/PoE2Dire/releases)
2. เปิดไฟล์ `PoE2Dire.user.js` จากรีลีส
3. ติดตั้งลงในตัวจัดการ userscript ของคุณ
4. ที่หน้ารายละเอียดการอัปเดตในฟอรัม Path of Exile ให้เปิดเมนูของตัวจัดการ userscript แล้วคลิก `Toggle PoE2Dire`

ผมทดสอบเฉพาะบน Firefox ร่วมกับ Tampermonkey และ ViolentMonkey เท่านั้น ถ้าใช้ไม่ได้ เปิด issue ได้เลย


### พวกคุณมีโทรศัพท์กันไหม?

ส่วนนี้สำหรับโทรศัพท์หรือเบราว์เซอร์ที่ไม่สามารถหรือไม่ต้องการติดตั้งส่วนขยาย

> [!NOTE]
> เบราว์เซอร์บนมือถือบางตัวบล็อกสคริปต์บุ๊กมาร์กเล็ต จึงอาจใช้ไม่ได้กับทุกคน ทดสอบบน `Android` ด้วย `Brave` ถ้าใช้ไม่ได้ ลองเปิด issue ดู อาจมีคนมีทางแก้สำหรับกรณีของคุณ

> [!CAUTION]
> การทำเช่นนี้จะดาวน์โหลดโค้ดจากระยะไกล (`https://aisatan.github.io/PoE2Dire/PoE2Dire-bookmarklet.js`) และ**รัน**ในเบราว์เซอร์ของคุณ
> ไม่จำเป็นต้องทำ แต่ผม**แนะนำอย่างยิ่ง**ให้ใช้**โหมดไม่ระบุตัวตน**เพื่อความปลอดภัย

วิดีโอการติดตั้งบนโทรศัพท์ของผม (เบราว์เซอร์ Brave):

https://github.com/user-attachments/assets/a034d803-7d16-443c-8e9b-e5f683d9e309

คุณภาพดีกว่า: https://youtube.com/shorts/AmYBZYfP4YY

บุ๊กมาร์กเล็ตสำหรับมือถือจะโหลดไฟล์บิลด์ไฟล์เดียวที่เผยแพร่บน GitHub Pages:

```js
javascript:(function(){var s=document.createElement('script');s.src='https://aisatan.github.io/PoE2Dire/PoE2Dire-bookmarklet.js?poe2dire=' + Date.now();s.referrerPolicy='no-referrer';s.onerror=function(){alert('PoE2Dire failed to load. The page may block bookmarklet scripts.');};document.documentElement.appendChild(s);})();
```

วิธีใช้งาน:

1. สร้างบุ๊กมาร์กในเบราว์เซอร์ (เว็บไซต์ใดก็ได้)
2. แก้ไข URL และชื่อของบุ๊กมาร์ก
3. วางโค้ด `javascript:` ทั้งหมดด้านบนลงในช่อง URL ของบุ๊กมาร์ก
4. ตั้งชื่อที่เรียกใช้ง่าย เช่น `0000 poe2dire`
5. เปิดหน้ารายละเอียดการอัปเดตในฟอรัม Path of Exile
6. เรียกใช้บุ๊กมาร์ก (ในเบราว์เซอร์ส่วนใหญ่ แค่พิมพ์ชื่อบุ๊กมาร์กก็จะเจอและเปิดใช้ได้)
